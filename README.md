# คู่มือการติดตั้งและใช้งาน Web App ระบบขอฝึกงาน กลุ่มมิตรผล (Mitr Phol Internship)

ระบบ Web Application สำหรับรับสมัครและบริหารจัดการนักศึกษาฝึกงานของกลุ่มมิตรผล ทำงานร่วมกับ Google Sheets และ Google Drive ผ่าน Google Apps Script

---

## 📁 โครงสร้างไฟล์ในโปรเจกต์

| ชื่อไฟล์ | ประเภท | คำอธิบาย |
|---|---|---|
| `Code.gs` | Apps Script | Backend API จัดการ Routing (`doGet`), บันทึกข้อมูลใบสมัคร (`processForm`), อัปโหลดไฟล์ไป Google Drive, ตรวจสอบสิทธิ์ผู้ใช้ (`checkCompanyLogin`) และจัดการสถานะใบสมัคร |
| `Index.html` | HTML / Frontend | หน้าหลักสำหรับ **นักศึกษา** กรอกแบบฟอร์มขอฝึกงาน อัปโหลดรูปโปรไฟล์และเอกสารแนบ พร้อมปุ่มและ Modal สำหรับเข้าสู่ระบบของเจ้าหน้าที่ |
| `User.html` | HTML / Frontend | หน้า **User Dashboard** สำหรับเจ้าหน้าที่ทั่วไป ตรวจสอบรายการผู้สมัคร กรองข้อมูล กดรับเรื่อง (`Claim`) และอนุมัติผล (`Approve`) พร้อมดูประวัติย้อนหลัง |
| `Admin.html` | HTML / Frontend | หน้า **Admin Dashboard** สำหรับผู้ดูแลระบบ สามารถจัดการสิทธิ์ อนุมัติ ยกเลิกการอนุมัติ (`Cancel Approval`) และเปลี่ยนตัวผู้รับเรื่อง (`Change Reviewer`) |

## 📊 โครงสร้าง Google Sheets (Spreadsheet: "Internship MPV")

ในไฟล์ Google Sheets ให้สร้าง 3 ชีต (Tabs) ดังนี้:

### 1. ชีต `ข้อมูลผู้สมัคร`
ประกอบด้วย 23 คอลัมน์ (คอลัมน์ A ถึง W):
- **A (Col 1):** ประทับเวลา (Timestamp)
- **B (Col 2):** สถานที่สมัคร (Location เช่น โรงงานน้ำตาลมิตรภูเวียง, โรงงานน้ำตาลมิตรภูหลวง)
- **C (Col 3):** ชื่อ-สกุล (Full Name)
- **D (Col 4):** ชื่อเล่น (Nick Name)
- **E (Col 5):** เบอร์โทรศัพท์ (Phone)
- **F (Col 6):** Line ID
- **G (Col 7):** E-mail ตอบกลับนักศึกษา
- **H (Col 8):** E-mail ตอบกลับสถาบัน
- **I (Col 9):** ที่อยู่ตามทะเบียนบ้าน
- **J (Col 10):** วุฒิการศึกษา (ปวช. / ปวส. / ปริญญาตรี / ปริญญาโท / อื่นๆ)
- **K (Col 11):** สถาบันการศึกษา
- **L (Col 12):** สาขา
- **M (Col 13):** วันเริ่มต้นขอฝึกงาน
- **N (Col 14):** วันสิ้นสุดขอฝึกงาน
- **O (Col 15):** หน่วยงานที่ต้องการฝึกงาน (ด้านโรงงาน / ด้านอ้อย / ด้านโลจิสติกส์)
- **P (Col 16):** ความสามารถพิเศษ
- **Q (Col 17):** ชื่อ-สกุล ผู้ติดต่อฉุกเฉิน
- **R (Col 18):** เบอร์โทร ผู้ติดต่อฉุกเฉิน
- **S (Col 19):** Profile (ลิงก์รูปภาพใน Google Drive)
- **T (Col 20):** เอกสารแนบ (Resume, Transcript, ID Card ลิงก์ใน Google Drive)
- **U (Col 21):** สถานะ (`unassigned` / `pending` / `reviewed`)
- **V (Col 22):** ผู้พิจารณา (Reviewer Username)
- **W (Col 23):** วันที่พิจารณา (Reviewed At)

### 2. ชีต `User`
ตารางข้อมูลเจ้าหน้าที่และบทบาทสิทธิ์การใช้งาน (ตรงตามภาพ):
- **Col A (Index 0):** รหัสพนักงาน (เช่น `4172`, `4177`)
- **Col B (Index 1):** คำนำหน้า (เช่น `นาย`, `น.ส.`)
- **Col C (Index 2):** ชื่อ (เช่น `อธิวิทย์`, `ไกรสร`)
- **Col D (Index 3):** นามสกุล (เช่น `ฤทธิ์บริรักษ์`)
- **Col E (Index 4):** ชื่อตำแหน่ง (เช่น `หัวหน้าแผนกเคมี`, `HR Business Partner`)
- **Col F (Index 5):** ฝ่าย (เช่น `ด้านโรงงานน้ำตาลมิตรภูเวียง`)
- **Col G (Index 6):** ด้าน (เช่น `ด้านผลิต (ฝ่ายอาจารย์และวิจัย)`)
- **Col H (Index 7):** สายงาน
- **Col I (Index 8):** แผนก
- **Col K (Index 10):** Email พนักงาน (เช่น `ATIWIT.L@MITRPHOL.COM`)
- **Col L (Index 11):** ผู้บังคับบัญชาโดยตรง (ผบต.)
- **Col M (Index 12):** E-mail Approver
- **Col N (Index 13):** ผจล.
- **Col O (Index 14):** E-mail MD
- **Col P (Index 15):** Role (`User` หรือ `Admin`)
  - **User:** เข้าหน้า `User Dashboard` เพื่อกดรับ นศ. ฝึกงาน และอนุมัติผล
  - **Admin:** เข้าหน้า `Admin Dashboard` เพื่อบริหารจัดการสิทธิ์ ยกเลิกการอนุมัติ และเปลี่ยนผู้พิจารณา

### 3. ชีต `ประวัติการเลือก` (Action History)
บันทึกประวัติการกระทำอัตโนมัติ:
- **A:** ประทับเวลา
- **B:** การกระทำ (Claim / Approve / Cancel / UpdateReviewer)
- **C:** แถวข้อมูล (Row)
- **D:** ผู้ดำเนินการ
- **E:** หมายเหตุ

## 🚀 ขั้นตอนการติดตั้งและการ Deploy (นำไปใช้งาน)

1. เปิด Google Sheets ของท่าน (เช่น `Internship MPV`)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. สร้างและวางโค้ดตามไฟล์ดังนี้:
   - ไฟล์สคริปต์ `Code.gs` -> คัดลอกโค้ดจาก `Code.gs`
   - ไฟล์ HTML `Index.html` -> กดเครื่องหมาย `+` เลือก **HTML** ตั้งชื่อ `Index` แล้ววางโค้ดจาก `Index.html`
   - ไฟล์ HTML `User.html` -> กด `+` เลือก **HTML** ตั้งชื่อ `User` แล้ววางโค้ดจาก `User.html`
   - ไฟล์ HTML `Admin.html` -> กด `+` เลือก **HTML** ตั้งชื่อ `Admin` แล้ววางโค้ดจาก `Admin.html`
4. *(ทางเลือก)* กำหนดโฟลเดอร์ Google Drive สำหรับเก็บไฟล์แนบ:
   - เปิดไฟล์ `Code.gs` บรรทัดที่ 9 แก้ไข `const UPLOAD_FOLDER_ID = "...";` เป็น ID ของโฟลเดอร์ใน Google Drive ของท่าน
   - หากปล่อยว่างไว้ ระบบจะสร้างโฟลเดอร์ชื่อ `MitrPhol_Internship_Uploads` ใน My Drive ให้โดยอัตโนมัติ
5. กดบันทึก (Save) โครงการทั้งหมด (Ctrl + S)
6. ทำการ Deploy:
   - กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
   - เลือกประเภท: **เว็บแอป (Web app)**
   - ตั้งค่าดังนี้:
     - **คำอธิบาย (Description):** Mitr Phol Internship Web App v1
     - **ดำเนินการในฐานะ (Execute as):** **ฉัน (Me)** *(ใช้อีเมลของคุณ เพื่อให้สคริปต์มีสิทธิ์เข้าถึง Sheets และ Drive)*
     - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(เพื่อให้บุคคลภายนอก/นักศึกษากรอกใบสมัครได้)*
   - กด **ทำให้ใช้งานได้ (Deploy)** และให้สิทธิ์การเข้าถึง (Authorize Access)
7. คัดลอก URL ของ Web App เพื่อนำไปแชร์ให้นักศึกษาใช้งาน หรือใช้เข้าสู่ระบบ
